down, don't hammer it\n- **Fast failure**: Returns error immediately instead of timing out\n- **Self-healing**: Automatically attempts recovery\n\n### Why Exponential Backoff + Jitter?\n- **Prevents thundering herd**: All clients don't retry at once\n- **Protects servers**: Gradually increases load as system recovers\n- **Proven pattern**: Used by AWS, Google, etc.\n\n### Why Structured Logging?\n- **Machine parseable**: Can be aggregated and searched\n- **Rich context**: Timestamp, severity, user ID, etc.\n- **Compliance**: Required for audit trails\n\n---\n\n**Version**:
