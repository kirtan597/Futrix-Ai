PROJECT DESCRIPTION:

Futrix AI Career Twin is an intelligent career analysis platform that leverages 
artificial intelligence to help job seekers optimize their career path. The 
platform analyzes resumes using advanced NLP algorithms, extracts relevant skills 
and experience, matches candidates with suitable technology roles, and provides 
personalized career development recommendations.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

TECHNICAL STACK:

Frontend:
• React 18 with TypeScript
• Material-UI (MUI) for component library
• Vite for build tooling
• Recharts for data visualization
• Zustand for state management
• Deployed on Netlify

Backend:
• Node.js with Express 5 (REST API)
• Python with FastAPI (AI Engine)
• MongoDB Atlas (Cloud Database)
• JWT + Google OAuth 2.0 authentication
• Deployed on Render

KEY FEATURES:

1. Secure Authentication
   - Google OAuth 2.0 integration
   - Email magic link authentication
   - JWT token management with refresh rotation

2. AI-Powered Resume Analysis
   - PDF and text resume parsing
   - Skill extraction (160+ technical skills)
   - Experience level detection
   - Comprehensive profile building

3. Intelligent Role Matching
   - Match against 7 technology positions
   - Percentage-based scoring algorithm
   - Salary range estimation
   - Skills gap identification

4. Career Development Insights
   - Personalized career path recommendations
   - Skills progression roadmap
   - Learning resource suggestions
   - Industry trend analysis

5. Interactive Visualizations
   - Animated score ring
   - Skills radar chart
   - Role match cards
   - Career timeline
   - Skills heatmap

ARCHITECTURE:

The application follows a microservices architecture:

1. React Frontend (Netlify)
   └── Communicates via REST API →

2. Node.js API Server (Render)
   ├── Handles authentication & authorization
   ├── Manages database operations (MongoDB)
   └── Routes AI requests →

3. Python AI Engine (Render)
   ├── Processes resume text
   ├── Extracts skills using NLP
   └── Returns analysis results
